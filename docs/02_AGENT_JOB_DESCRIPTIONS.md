# Agent Job Descriptions

## Operating Principle

Agents are company workers inside controlled workflows. They do not own final decisions for sensitive matters.

## Department A - Customer Support

| Agent | Responsibility | Human Approval |
|---|---|---|
| Support Triage Agent | Classifies product, intent, urgency, and risk | Required for high/critical risk |
| Product Support Agent | Drafts product-specific support replies from approved knowledge | Human sends in MVP |
| Human Handoff Agent | Creates ticket and routes conversation to human | Not required |
| Bug Intake Agent | Converts user complaints into structured bug reports | Optional review |
| Billing Support Agent | Explains billing and plan information | Required for refunds/payment decisions |

## Department B - Sales and Growth

| Agent | Responsibility | Human Approval |
|---|---|---|
| Lead Qualification Agent | Identifies product interest, lead type, urgency, and next step | Optional |
| Demo Prep Agent | Prepares demo notes and product walkthroughs | Human conducts demo |
| Proposal Drafting Agent | Drafts proposal or pilot summaries | Required before sending |
| Follow-up Agent | Drafts reminders and follow-up messages | Required before sending |

## Department C - Product Operations

| Agent | Responsibility | Human Approval |
|---|---|---|
| Product Manager Agent | Maintains backlog suggestions, sprint notes, and priorities | Human approves scope |
| Feature Request Agent | Converts conversations into feature requests | Optional |
| Release Notes Agent | Drafts changelogs and release notes | Required before publishing |
| Product Analytics Agent | Highlights product issues from metrics | Human decides action |

## Department D - QA and Testing

| Agent | Responsibility | Human Approval |
|---|---|---|
| QA Checklist Agent | Generates test cases from feature scope | Optional |
| Bug Reproduction Agent | Converts bug reports into reproduction steps | Optional |
| Regression Agent | Maintains per-product regression checklists | Optional |
| Pre-Release Gate Agent | Produces release readiness reports | Human approves release |

## Department E - Documentation and Knowledge Base

| Agent | Responsibility | Human Approval |
|---|---|---|
| Documentation Agent | Drafts user guides, admin guides, and technical docs | Human approves publication |
| Knowledge Curator Agent | Converts repeated support questions into FAQ entries | Required before approved status |
| SOP Agent | Writes operating procedures | Human approves |

## Department F - Finance, Billing, and Admin

| Agent | Responsibility | Human Approval |
|---|---|---|
| Billing Agent | Tracks billing questions and drafts reminders | Required before sending |
| Pricing Agent | Maintains pricing notes and package comparisons | Required for custom pricing |
| Management Report Agent | Produces weekly/monthly summaries | Human reviews |

## Department G - Compliance, Trust, and Audit

| Agent | Responsibility | Human Approval |
|---|---|---|
| Compliance Triage Agent | Flags legal, financial, religious, contract, or certification risk | Always required for decisions |
| Audit Log Agent | Ensures important actions are traceable | Not required |
| Amanah Review Assistant | Summarizes evidence gaps for NGO review | Human decides certification |
| Contract Risk Assistant | Summarizes missing evidence or claim-sensitive items | Human decides entitlement |

## Department H - Developer and Technical Operations

| Agent | Responsibility | Human Approval |
|---|---|---|
| Repo Analyst Agent | Explains repo structure and dependencies | Not required |
| Patch Planner Agent | Prepares change plans and patch packs | Human reviews |
| Build Error Agent | Diagnoses build errors and proposes fixes | Human approves deployment |
| Migration Agent | Drafts SQL migration and rollback notes | Required before execution |
